Brain Vault - API Reference & Architecture

Complete documentation for all asynchronous REST API endpoints querying MongoDB via PyMongo's native AsyncMongoClient.

Authentication

JWT Bearer / Cookie
POST /api/v1/auth/signup

Register a new user account into MongoDB with bcrypt hashing.

POST /api/v1/auth/signin

Verify user credentials against MongoDB and receive JWT access token.

GET /api/v1/auth/me

Fetch current user document from MongoDB via PyMongo Async.

Knowledge & Links (CRUD)

Async Collection: content
GET /api/v1/content

Query saved knowledge with optional query parameters: folder_id, type, tag, q.

POST /api/v1/content

Insert new content document asynchronously into MongoDB.

PUT /api/v1/content/<id>

Update title, link, notes, folder, or tags for existing item.

DELETE /api/v1/content/<id>

Remove content document by ObjectId from collection.
